# 🎵 배경음악 폴더

이 폴더에 배경음악 파일을 추가하세요.

## 📁 지원 형식
- MP3 (.mp3)
- WAV (.wav)  
- M4A (.m4a)

## 💡 사용 방법
1. 이 폴더에 음악 파일 복사
2. Streamlit 앱 5단계에서 선택

## 📂 예시
```
music/
├── README.md
├── emotional_piano.mp3
├── cinematic_music.mp3
└── ambient_calm.mp3
```

## ⚠️ 저작권 주의!
YouTube Audio Library, Pixabay Music 등 **무료/저작권 없는 음악**만 사용하세요!

## 🔗 무료 음악 사이트
- YouTube Audio Library: https://www.youtube.com/audiolibrary
- Pixabay Music: https://pixabay.com/music/
